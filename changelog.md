# v1.1.0

- New **Render** tab: render a macro to an `.mp4` video through FFmpeg.
- Resolution, frame rate, encoder, bitrate, audio and end-delay options.
- Playback no longer skips inputs, and recording and playback use the same frame numbers.

- First release.
- Record and play macros in the `.gdr2` format.
- Modern menu, opened with **P**.
- Macro library, auto-save, practice mode fix, speed control and a status overlay.
